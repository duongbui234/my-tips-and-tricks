## Lưu ý

- Sao lưu dotfiles trước khi chỉnh cấu hình.
- Không đưa token, API key, SSH private key hay kubeconfig vào Git.
- Chỉ chạy lệnh xóa tài nguyên sau khi xác minh đúng môi trường.
- Các lệnh cài đặt có thể thay đổi theo phiên bản; ưu tiên kiểm tra tài liệu chính thức được liên kết trong từng bài.
